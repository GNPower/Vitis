# ZedBoard example project

A small, self-contained Vitis-On-Git project used to test `CREATE` and `BUILD`
against a real Vitis client. It builds a standalone "hello world" application on
a ZedBoard (Zynq-7000, `ps7_cortexa9_0`).

The application is [`src/example_app/main.c`](src/example_app/main.c),
and the hardware is a Vivado script, [`hdl/make_xsa.tcl`](hdl/make_xsa.tcl), that
generates a minimal `.xsa` (a bare Zynq-7000 PS with UART1). No additional hardware
design and no external firmware are committed, so the project builds anywhere
Vivado and Vitis 2024.1 are installed.

## Layout

```text
examples/zedboard/
├── hdl/make_xsa.tcl               # Vivado script that generates the .xsa
└── src/
    ├── Top/zedboard/              # the project config CREATE reads
    │   ├── vitis.conf             # platform + application list
    │   ├── platform.conf          # XSA source, boot components, one domain
    │   ├── domain.conf            # standalone OS, UART1 stdio
    │   └── application.conf       # empty template + main.c, -O2 -g3
    └── example_app/main.c         # the one source file compiled into the app
```

## What the CI job does

[`.github/workflows/example-build.yml`](../../.github/workflows/example-build.yml)
runs on a self-hosted runner with Vivado and Vitis 2024.1. It:

1. Generates `hdl/data/ZedBoard.xsa` by running `make_xsa.tcl` in Vivado.
2. Assembles the workspace the tool expects (it anchors its paths to `src/Vitis`):

```text
<workspace>/
├── hdl/data/ZedBoard.xsa   # generated in step 1
└── src/
    ├── Vitis/        # this repo (checked out with path: src/Vitis)
    ├── Top/zedboard/ # copied from examples/zedboard/src/Top
    ├── example_app/  # copied from examples/zedboard/src/example_app
    └── Projects/     # generated by CREATE
```

3. Runs `./Vitis/Do CREATE zedboard` (platform + BSP + FSBL + app via the Vitis server)
   and `./Vitis/Do BUILD hello --tools ninja` (rebuilds the app directly), and checks
   that `hello.elf` was produced.

## Build it locally

From a machine with Vivado and Vitis 2024.1 on `PATH`:

```bash
# from an empty workspace directory
git clone https://github.com/GNPower/Vitis.git src/Vitis
mkdir -p hdl/data
vivado -mode batch -source src/Vitis/examples/zedboard/hdl/make_xsa.tcl \
       -tclargs "$(pwd)/hdl/data/ZedBoard.xsa"
cp -r src/Vitis/examples/zedboard/src/Top         src/Top
cp -r src/Vitis/examples/zedboard/src/example_app src/example_app
cd src

./Vitis/Do CREATE zedboard
./Vitis/Do BUILD hello --tools ninja
# result: src/Projects/hello/build/hello.elf
```
